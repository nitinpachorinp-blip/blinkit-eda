# 🛒 Blinkit Exploratory Data Analysis (EDA) Using Python

A complete Exploratory Data Analysis (EDA) project on Blinkit grocery sales data using Python. This project focuses on analyzing sales trends, customer preferences, outlet performance, product categories, and business insights through data visualization and statistical analysis.

The project demonstrates practical data analysis skills including data cleaning, preprocessing, visualization, and insight generation using Python libraries.

---

# 📌 Project Overview

The objective of this project is to analyze Blinkit grocery sales data and uncover meaningful business insights that can help improve:

* Sales performance
* Product demand analysis
* Outlet efficiency
* Customer purchasing behavior
* Inventory management
* Business decision-making

This project simulates real-world retail and grocery analytics workflows.

# 📂 Dataset Information

The dataset contains Blinkit grocery sales and outlet information.

## Main Columns

| Column Name          | Description                 |
| -------------------- | --------------------------- |
| Item Identifier      | Unique item code            |
| Item Type            | Product category            |
| Item Fat Content     | Low Fat / Regular           |
| Outlet Identifier    | Unique outlet code          |
| Outlet Size          | Small / Medium / High       |
| Outlet Location Type | Tier 1 / Tier 2 / Tier 3    |
| Outlet Type          | Grocery Store / Supermarket |
| Item Visibility      | Product visibility score    |
| Item Weight          | Product weight              |
| Sales                | Total sales amount          |
| Rating               | Customer rating             |
| Establishment Year   | Outlet establishment year   |

# 🔍 Key Business Insights

* Tier 3 outlets contribute the highest overall sales.
* Snack foods and fruits generate strong revenue.
* Medium-sized outlets perform better in sales distribution.
* Higher visibility products tend to achieve more sales.
* Customer ratings positively influence product performance.
